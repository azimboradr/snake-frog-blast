# Model asset standards

Place **real binary .glb** files here, not text placeholders.

Planned files:
- snake.glb — custom snake head, body UV/skin and compatible animation
- frog.glb — textured frog with hop animation
- spider.glb — articulated 8-leg spider
- trees.glb — natural tree variants with UVs
- rocks.glb — rock and mossy-log variants

Before integration: record the original source URL, license, attribution, polygon count, texture resolution, animations and mobile performance. Do not commit copyrighted models without permission. Models not yet acquired.

Coordinate convention: Three.js Y-up, ground at Y=0, game travel on X/Z. Center pivots consistently. Prefer glTF 2.0 PBR and KTX2 where supported.
